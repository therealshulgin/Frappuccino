Ce site est conçu pour respecter la vie privée de celles et ceux qui le consultent, avec la même posture que l'outil qu'il présente.

- **Aucun traqueur, aucune analyse d'audience.** Pas de Google Analytics, pas de Plausible, pas de Matomo : rien ne compte ni ne profile les visiteurs.
- **Aucune requête tierce.** Pas de police externe, pas de CDN, pas de widget embarqué, pas de script social. Chaque ressource est servie depuis ce domaine.
- **Aucun cookie, aucun stockage local, aucune empreinte de navigateur.**
- **Aucun framework JavaScript.** Le site est du HTML et du CSS statiques ; la rare interactivité est du code minimal écrit à la main.
- **Aucune journalisation des visiteurs côté serveur.** Les journaux d'accès sont désactivés : aucune adresse IP, aucun user-agent, aucun historique de requête n'est enregistré.
- **Généré hors-serveur.** Le site est construit sur une machine séparée ; le serveur ne fait que servir des fichiers statiques : il n'a rien à lire sur vous, et rien à divulguer.

Nous ne collectons rien, parce que la façon la plus sûre de protéger des données est de ne pas les détenir.

Pour la posture de sécurité de l'application elle-même (modèle de menace, ce qu'elle protège et ne protège pas), voir la [page d'accueil](@/_index.fr.md) et la [page positionnement](@/positioning.fr.md).
